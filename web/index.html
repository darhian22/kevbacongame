    FROM ASSIGNMENT TO EXPLORATION

    A graph you can follow, not just query.

    The original CS 10 project models actors as vertices and shared films as edges, then uses breadth-first search to find a shortest path. I built this browser interface to make that result visible: each actor is a node, each film is a labeled connection, and the highlighted route shows the algorithm's answer step by step.

    The visual exploration was inspired by my separate Connection Atlas prototype. Both interfaces let someone choose endpoints and follow a shortest route through a network; this version applies that interaction to the actor-and-film graph from my submitted project.

    Actor and film data are loaded from the included project dataset. The Java command-line game remains available alongside this explorer.
